# CorpApp

Демонстрационное (MVP) мобильное приложение условного корпоративного портала компании.

Проектная работа. Приложение собрано на **SwiftUI** с архитектурой **Flux**.

## Важно

> - Приложение предназначено только для авторизованных пользователей.  
> - Тестовый логин / пароль: `d.fedorova` / `000000`.  
> - При необходимости проверку пароля можно отключить в `MockNetworkService` в методе `login`.
> - По задумке приложение распространяется с использованием Enterprise-сертификата компании.
> - Сейчас работает **только на моковых данных**. Все данные вымышлены, любые совпадения случайны.
> - Реальные сетевые запросы и серверная авторизация не реализованы.
> - В приложении реализована таб-навигация с независимыми стеками.

## Требования

- Xcode 16+
- iOS 17+
- Swift 5.9+

## Запуск на своём устройстве

1. Открой проект в Xcode.
2. Выбери таргет **CorpApp**.
3. Перейди в **Signing & Capabilities**.
4. В поле **Team** выбери свою учётную запись / команду разработчика.
5. При необходимости измени **Bundle Identifier**.
6. Подключи устройство и запусти приложение.

Без указания своей команды сборка на физическое устройство завершится ошибкой подписи.

## Архитектура

Проект использует Flux-подход:

- `Store` + `Actions` для экранов
- `AppRouter` для навигации
- `ServiceLocator` для зависимостей
- Разделение на Domain / Core / Features

## Структура

```
CorpApp/
├── App/                  # Точка входа, RootStore, Configurator
├── Core/                 # Сервисы, ServiceLocator
├── Domain/               # Модели и протоколы
├── Features/             # Экраны и их Store/Actions
├── Navigation/           # AppRouter, маршруты, MainTabView
├── Resources/            # Ассеты, Launch Screen
└── UI/                   # Вспомогательные общие экраны
```

## Авторизация

Экран авторизации на моковых данных.  
Тестовый вход: `d.fedorova` / `000000`. Имитация загрузки — около 4 секунд.

При успешной авторизации открывается основной экран приложения. Данные для реавторизации сохраняются через `KeychainService`.

При повторном запуске (после выгрузки из памяти) выполняется попытка реавторизации. При успехе пользователь сразу попадает в приложение, при неудаче — остаётся на экране входа.

После выхода через личный кабинет реавторизация не срабатывает — требуется повторный ввод логина и пароля.

## Стена

Первый таб.  
Сверху: фильтр по тегам, кнопка перехода к полезной информации, список постов.  
При выборе тега список фильтруется. Нажатие на «Полезная информация» открывает соответствующий раздел.

## Полезная информация

Список статей. При открытии статьи показываются заголовок, текст и контакты сотрудников, к которым можно обратиться.  
Нажатие на сотрудника открывает его карточку (подробнее в разделе [Сотрудники и команды](#сотрудники-и-команды)).

## Сотрудники и команды

Второй таб.  
Переключатель «Команды / Сотрудники».

**Команды** — список всех команд. При открытии команды видны маскот, название, руководитель и участники. Руководитель и участники кликабельны.

**Сотрудники** — поиск + список. Поиск работает по ФИО, городу, контактам, названию команды и должности.

Карточка сотрудника содержит аватар, ФИО, должность, команду, руководителя, город, день рождения, почту и Telegram.  
Команда, руководитель, почта и Telegram интерактивны:
- команда → экран команды;
- руководитель → карточка руководителя;
- почта → почтовый клиент;
- Telegram → приложение Telegram (если установлено).

Навигация внутри таба неограничена. Повторное нажатие на таб возвращает в корень.

## Личный кабинет

Третий таб.  
Содержит блок быстрых действий (Трудозатраты, Моя команда, Настройки), информацию о пользователе и кнопку выхода.

Если есть незаполненные трудозатраты, на табе и на кнопке «ТРЗ» отображается бейдж с количеством пропущенных дней.

## Трудозатраты

Открывается из личного кабинета или по пуш-уведомлению.

Содержит:
- интерактивный календарь;
- список проектов для заполнения;
- кнопки добавления проекта и сохранения.

Цвета и маркеры дней:
- обычный текст — рабочий день;
- серый — выходной / праздник;
- тёмный — даты после сегодняшней;
- синий маркер — выбранная дата;
- оранжевый маркер — незаполненный день.

Будущие и нерабочие дни выбрать нельзя.  
После сохранения пропущенного дня счётчик на бейджах уменьшается.

## Настройки

Открываются из личного кабинета.

**Уведомления** — включение напоминания о ТРЗ, выбор времени, переход в системные настройки.  
**Оформление** — системная тема или ручной выбор светлой/тёмной.

Внизу отображается версия приложения.

## Уведомления

Можно включить ежедневное локальное напоминание «Заполни ТРЗ».

При первом включении система запросит разрешение. Если пользователь отказал, разрешение можно дать позже в системных настройках (кнопка «Открыть системные настройки» ведёт туда).

При нажатии на уведомление приложение открывается сразу на экране трудозатрат.
