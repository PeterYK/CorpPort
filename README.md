# CorpPort
(само приложение названо переименовано в CorpApp)
Демонстрационное мобильное приложение корпоративного портала компании.

Проектная работа. Приложение собрано на **SwiftUI** с архитектурой **Flux**.

## Возможности

- Авторизация (на моковых данных)
- Стена (новостная лента с тегами)
- Сотрудники и команды
- Личный кабинет
- Трудозатраты (календарь, проекты, сохранение)
- Полезная информация
- Локальные уведомления
- Настройки темы и напоминаний

## Важно

> Приложение в данный момент работает **только на моковых данных**.  
> Реальные сетевые запросы и серверная авторизация не реализованы.

## Требования

- Xcode 16+
- iOS 17+
- Swift 5.9+

## Запуск на своём устройстве

1. Открой проект в Xcode.
2. Выбери таргет **CorpPort**.
3. Перейди в **Signing & Capabilities**.
4. В поле **Team** выбери свою учётную запись / команду разработчика.
5. При необходимости измени **Bundle Identifier**.
6. Подключи устройство и запусти приложение.

Без указания своей команды сборка на физическое устройство завершится ошибкой подписи.

## Архитектура

Проект использует Flux-подход:

- `Store` + `Actions` для экранов
- `AppRouter` для навигации
- `ServiceLocator` для зависимостей
- Разделение на Domain / Core / Features

## Структура

```
CorpPort/
├── App/                  # Точка входа, RootStore, Configurator
├── Core/                 # Сервисы, ServiceLocator
├── Domain/               # Модели и протоколы
├── Features/             # Экраны и их Store/Actions
├── Navigation/           # AppRouter, маршруты, MainTabView
└── Resources/            # Ассеты, Launch Screen
```
